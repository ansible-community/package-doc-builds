fortios_firewall_shaping_profile – Configure shaping profiles in Fortinet’s FortiOS and FortiGate¶

New in version 2.8.

  • Synopsis

  • Requirements

  • Parameters

  • Notes

  • Examples

  • Return Values

  • Status

Synopsis¶

  • This module is able to configure a FortiGate or FortiOS by allowing the user to configure firewall feature and shaping_profile category. Examples includes all options and need to be adjusted to datasources before usage. Tested with FOS v6.0.2

Requirements¶

The below requirements are needed on the host that executes this module.

  • fortiosapi>=0.9.8

Notes¶

Note

  • Requires fortiosapi library developed by Fortinet

  • Run as a local_action in your playbook

Examples¶

- hosts: localhost
  vars:
   host: "192.168.122.40"
   username: "admin"
   password: ""
   vdom: "root"
  tasks:
  - name: Configure shaping profiles.
    fortios_firewall_shaping_profile:
      host:  "{{ host }}"
      username: "{{ username }}"
      password: "{{ password }}"
      vdom:  "{{ vdom }}"
      https: "False"
      firewall_shaping_profile:
        state: "present"
        comment: "Comment."
        default-class-id: "4"
        profile-name: "<your_own_value>"
        shaping-entries:
         -
            class-id: "7"
            guaranteed-bandwidth-percentage: "8"
            id:  "9"
            maximum-bandwidth-percentage: "10"
            priority: "high"
