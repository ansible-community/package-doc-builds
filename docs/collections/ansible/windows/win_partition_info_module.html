ansible.windows.win_partition_info module – Gather information about Windows disk partitions

Note

This module is part of the ansible.windows collection (version 3.9.2).

You might already have this collection installed if you are using the ansible package. It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install ansible.windows.

To use it in a playbook, specify: ansible.windows.win_partition_info.

New in ansible.windows 3.10.0

  • Synopsis

  • Parameters

  • Notes

  • See Also

  • Examples

  • Return Values

Synopsis

  • Gather information about all partitions or partitions matching the specified filters.

Parameters

Parameter

Comments

disk_number

integer

Return partitions on this disk.

Disk numbers start at 0.

drive_letter

string

Return the partition with this drive letter.

This option is mutually exclusive with disk_number and partition_number.

partition_number

integer

Return partitions with this partition number.

Can be used by itself to search all disks or together with disk_number to identify a partition.

Partition numbers start at 1.

Notes

Note

  • Requires Windows 8 or Windows Server 2012 (NT 6.2) or newer.

See Also

See also

ansible.windows.win_partition

Creates, changes and removes partitions on Windows Server.

Examples

- name: Get information about all partitions
  ansible.windows.win_partition_info:
  register: partition_info

- name: Get information about a partition by disk and partition number
  ansible.windows.win_partition_info:
    disk_number: 1
    partition_number: 2
  register: partition_info

- name: Get information about the partition with drive letter D
  ansible.windows.win_partition_info:
    drive_letter: D
  register: partition_info

Return Values

Common return values are documented here, the following are the fields unique to this module:

Key

Description

boolean

Whether any partitions were found with the specified filters.

Returned: always

Returned: always

Returned: success

integer
