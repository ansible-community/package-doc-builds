vmware.vmware.vm_info module – Gather VM information

Note

This module is part of the vmware.vmware collection (version 2.13.0).

You might already have this collection installed if you are using the ansible package. It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install vmware.vmware. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: vmware.vmware.vm_info.

Synopsis

  • This module gathers information about one or more VMs.

  • Gathering all properties or only a targeted subset has a similar runtime, so playbooks can use any information associated with a VM without a significant performance cost.

Aliases: guest_info

Requirements

The below requirements are needed on the host that executes this module.

  • vSphere Automation SDK

Parameters

Parameter

Comments

datacenter

aliases: datacenter_name

string

The datacenter with the VM you would like to query.

This is only used if the folder parameter is supplied as a relative path.

folder

string

Absolute or relative folder path to search for the virtual machine(s).

For example ‘datacenter name/vm/path/to/folder’ or ‘path/to/folder’

This parameter can be used on its own to specify a folder to search recursively for VMs.

folder_paths_are_absolute

boolean

If true, any folder path parameters are treated as absolute paths.

If false, modules will try to intelligently determine if the path is absolute or relative.

This option is useful when your environment has a complex folder structure. By default, modules will try to intelligently determine if the path is absolute or relative. They may mistakenly prepend the datacenter name or other folder names, and this option can be used to avoid this.

Choices:

  • false ← (default)

  • true

gather_compute_objects

boolean

If true, information about the VM’s ESXi host, cluster, and resource pool will be included in the output.

This gives more detailed information about these objects than what VM properties alone can provide.

Choices:

  • false ← (default)

  • true

gather_identity

boolean

If true, gather the identity information from the REST API.

This populates the identity value in the return output.

This adds an additional API call per VM. All of the information obtained with these calls can be gathered more efficiently using the properties option.

Choices:

  • false

  • true ← (default)

gather_location_objects

boolean

If true, information about the VM’s folder and datacenter will be included in the output.

This gives more detailed information about these objects than what VM properties alone can provide.

Choices:

  • false ← (default)

  • true

gather_tags

boolean

If true, gather any tags attached to the VM(s).

Setting this option means that one additional REST API call will be done per VM.

Choices:

  • false ← (default)

  • true

guest_password

string

The password of the user to be used to connect to guest vm and fetch environment info.

Setting this option means that one additional REST API call will be done per VM.

This must be supplied with guest_username.

guest_username

string

The username to be used to connect to guest vm and fetch environment info.

Setting this option means that one additional REST API call will be done per VM.

This must be supplied with guest_password.

hostname

string

The hostname or IP address of the vSphere vCenter server.

If the value is not specified in the task, the value of environment variable VMWARE_HOST will be used instead.

moid

string

The MOID of the vm to gather info for

Only one of name, moid, uuid is allowed

name

aliases: guest_name

string

The name of the vm to gather info for

Only one of name, moid, uuid is allowed

name_match

string

If using name and multiple VMs have the same name, specify which VM should be selected

Choices:

  • "first"

  • "last"

password

aliases: pass, pwd

string

The password of the vSphere vCenter server.

If the value is not specified in the task, the value of environment variable VMWARE_PASSWORD will be used instead.

port

integer

The port number of the vSphere vCenter server.

If the value is not specified in the task, the value of environment variable VMWARE_PORT will be used instead.

Default: 443

properties

list / elements=string

The list of VM properties to gather. This is only used when schema=vsphere.

The gather_* options may add properties to this list.

If omitted, or if the keyword ‘all’ is supplied in the list, all properties are gathered, which can produce a large amount of output.

If set to an empty list, only properties required by the relevant gather_* options are returned. Use this to get a minimal output or if you are unsure what about the property names.

Adding properties does not significantly increase runtime.

proxy_host

string

The address of a proxy that will receive all HTTPS requests and relay them.

The format is a hostname or a IP.

If the value is not specified in the task, the value of environment variable VMWARE_PROXY_HOST will be used instead.

proxy_port

integer

The port of the HTTP proxy that will receive all HTTPS requests and relay them.

If the value is not specified in the task, the value of environment variable VMWARE_PROXY_PORT will be used instead.

proxy_protocol

aliases: protocol

string

The proxy connection protocol to use.

This option is used if the correct proxy protocol cannot be automatically determined.

Choices:

  • "http"

  • "https" ← (default)

schema

string

The type of info to gather from the VMs.

The default value of summary is for backwards compatibility. Users should prefer the vsphere schema with a list of properties.

The summary option provides a curated list of VM parameters with custom names. Its performance is noticeably worse than the equivalent search using vsphere and properties.

Choices:

  • "summary" ← (default)

  • "vsphere"

use_instance_uuid

boolean

If true, search by instance UUID instead of BIOS UUID.

BIOS UUID may not be unique and may cause errors.

Choices:

  • false

  • true ← (default)

username

aliases: admin, user

string

The username of the vSphere vCenter server.

If the value is not specified in the task, the value of environment variable VMWARE_USER will be used instead.

uuid

string

The UUID of the vm to gather info for

Only one of name, moid, uuid is allowed

validate_certs

boolean

Allows connection when SSL certificates are not valid. Set to false when certificates are not trusted.

If the value is not specified in the task, the value of environment variable VMWARE_VALIDATE_CERTS will be used instead.

Choices:

  • false

  • true ← (default)

Notes

Note

  • All modules require API write access and hence are not supported on a free ESXi license.

  • All variables and VMware object names are case sensitive.

  • Modules may rely on the ‘requests’ python library, which does not use the system certificate store by default. You can specify the certificate store by setting the REQUESTS_CA_BUNDLE environment variable. Note having this variable set may cause a ‘false’ value for the ‘validate_certs’ option to be ignored in some cases. Example: ‘export REQUESTS_CA_BUNDLE=/path/to/your/ca_bundle.pem’

Examples

- name: Gather guest vm info
  vmware.vmware.vm_info:
    hostname: "https://vcenter"
    username: "username"
    password: "password"
    validate_certs: false
    guest_name: "my_vm"

# The examples below use the vsphere schema with targeted properties. This is the most
# efficient way to gather information. Properties use the vSphere property path syntax
# and the results are nested to match, for example guest.net is returned under vms[*].guest.net.

- name: Gather basic info about every VM in a folder
  vmware.vmware.vm_info:
    folder: "/my-datacenter/vm/production"
    gather_identity: false
    schema: vsphere
    properties:
      - name
      - runtime.powerState
      - config.guestFullName
      - config.hardware.numCPU
      - config.hardware.memoryMB
  register: vm_basics

- name: Gather power state and host placement for all VMs in the vCenter
  vmware.vmware.vm_info:
    gather_identity: false
    schema: vsphere
    properties:
      - name
      - runtime.powerState
      - runtime.host
      - resourcePool
  register: vm_placement

- name: Gather disk and storage info for a single VM
  vmware.vmware.vm_info:
    folder: "/my-datacenter/vm/production"
    name: my_vm
    gather_identity: false
    schema: vsphere
    properties:
      - name
      # virtual disks, and other devices, attached to the VM
      - config.hardware.device
      # datastore usage in bytes
      - storage.perDatastoreUsage
      # the datastores the VM files live on
      - datastore
  register: vm_storage

- name: Gather guest OS disk usage for all VMs in a folder
  # This requires VMware tools to be running in the guest
  vmware.vmware.vm_info:
    folder: "/my-datacenter/vm/production"
    gather_identity: false
    schema: vsphere
    properties:
      - name
      - guest.disk
  register: vm_guest_disks

- name: Report guest filesystems that are over 90% full
  ansible.builtin.debug:
    msg: "{{ item.0.name }} {{ item.1.diskPath }} is nearly full"
  loop: "{{ vm_guest_disks.vms | subelements('guest.disk', skip_missing=true) }}"
  when: (1 - (item.1.freeSpace / item.1.capacity)) > 0.9

- name: Gather network info for all VMs in a folder
  # This requires VMware tools to be running in the guest
  vmware.vmware.vm_info:
    folder: "/my-datacenter/vm/production"
    gather_identity: false
    schema: vsphere
    properties:
      - name
      # the guest's primary IP address
      - guest.ipAddress
      # per-NIC IP addresses, MAC addresses, and the connected network
      - guest.net
      # the port groups the VM is attached to
      - network
  register: vm_networks

- name: Gather the IP address of a single VM
  vmware.vmware.vm_info:
    name: my_vm
    gather_identity: false
    schema: vsphere
    properties:
      - guest.ipAddress
  register: vm_ip

- name: Gather resource usage for all VMs in a folder
  vmware.vmware.vm_info:
    folder: "/my-datacenter/vm/production"
    gather_identity: false
    schema: vsphere
    properties:
      - name
      - summary.quickStats
      - config.hardware.numCPU
      - config.hardware.memoryMB
  register: vm_usage

- name: Gather VMware tools and hardware version info for all VMs in a folder
  vmware.vmware.vm_info:
    folder: "/my-datacenter/vm/production"
    gather_identity: false
    schema: vsphere
    properties:
      - name
      - guest.toolsStatus
      - guest.toolsRunningStatus
      - guest.toolsVersion
      - config.version
