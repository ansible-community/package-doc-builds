Collection version 5.0.0

  • Plugin Index

Description

VMware collection for Ansible

Author:

  • Ansible (https://github.com/ansible)

Supported ansible-core versions:

  • 2.16.0 or newer

  • Issue Tracker
  • Repository (Sources)
