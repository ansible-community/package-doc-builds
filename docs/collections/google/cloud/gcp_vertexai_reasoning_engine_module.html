google.cloud.gcp_vertexai_reasoning_engine module – Manages a VertexAI.ReasoningEngine resource

Note

This module is part of the google.cloud collection (version 1.15.0).

You might already have this collection installed if you are using the ansible package. It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install google.cloud. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: google.cloud.gcp_vertexai_reasoning_engine.

  • Requirements

  • Parameters

  • Notes

Synopsis

  • ReasoningEngine provides a customizable runtime for models to determine which actions to take and in which order.

Requirements

The below requirements are needed on the host that executes this module.

  • python >= 3.8

  • requests >= 2.18.4

  • google-auth >= 2.25.1
