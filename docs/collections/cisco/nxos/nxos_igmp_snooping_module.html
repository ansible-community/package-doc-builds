cisco.nxos.nxos_igmp_snooping module – IGMP snooping resource module.

Note

This module is part of the cisco.nxos collection (version 14.0.0).

You might already have this collection installed if you are using the ansible package. It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install cisco.nxos.

To use it in a playbook, specify: cisco.nxos.nxos_igmp_snooping.

New in cisco.nxos 1.0.0

  • Synopsis

  • Parameters

  • Notes

  • Examples

  • Return Values

Synopsis

  • This module manages the global IGMP snooping configuration and the IGMP snooping settings of the per-VLAN context (vlan configuration <id>), including static groups, multicast router ports, the querier and report policies, on devices running Cisco NX-OS.

Note

This module has a corresponding action plugin.

Aliases: igmp_snooping

running_config

string

added in cisco.nxos 14.0.0

This option is used only with state parsed.

The value of this option should be the output received from the NX-OS device by executing the commands show running-config | section “^vlan configuration” and show running-config | include “^ip igmp snooping|^no ip igmp snooping”, or the full running configuration.

The state parsed reads the configuration from running_config option and transforms it into Ansible structured data as per the resource module’s argspec and the value is then returned in the parsed key within the result.

state

string

The state the configuration should be left in.

The states and the call shape changed in 14.0.0. Only the resource module states exist, the former present and default states are replaced by merged and deleted.

With merged what is given is added to the device, nothing is removed. A setting that is not given is not touched.

With replaced the global settings that are not given are reset to their default, the listed VLANs are made identical to the given ones and the other VLANs are not touched.

With overridden the same applies and the VLANs that are not listed are removed.

With deleted and without config all global settings are reset to their default and all vlan configuration blocks are removed. With config the listed global settings are reset, a listed VLAN without any setting is removed, and for a listed VLAN with settings only these are removed.

With gathered the configuration is read from the device.

With rendered the commands for config are returned without connecting to the device.

With parsed running_config is returned as structured data.

Choices:

  • "merged" ← (default)

  • "replaced"

  • "overridden"

  • "deleted"

  • "gathered"

  • "rendered"

  • "parsed"

Notes

Note

  • Tested against NX-OS 10.6(4) on N9K-C93180YC-FX.

  • Unsupported for Cisco MDS.

  • The module was rewritten as a resource module, the former flat parameters and the present and default states are replaced by config with the state merged or deleted.

  • NX-OS does not display a setting that has its default value. The global settings are therefore gathered with their effective value, a setting of a VLAN that is equal to its default counts as not set, and an option that is given with its default value removes its line.

  • A vlan configuration block is managed completely. With state replaced or overridden a listed VLAN gets exactly the given settings. state deleted without config and state overridden also remove the blocks that are not listed, also those created by other tools, so run the task in check mode first.

  • The device keeps one policy per interface, so an interface can only be used once in report_policy and access_group.

  • The proxy with mrt 5, the default, is not stored by the device, omit mrt instead.

  • IGMP snooping over VXLAN needs BGP EVPN and the global vxlan setting, and the configuration must be identical on both vPC peers.

  • This module works with connection network_cli and httpapi. See https://docs.ansible.com/ansible/latest/network/user_guide/platform_nxos.html

  • The parsed state reads configuration from running_config and does not connect to the device.

# nxos# show running-config | section "^vlan configuration|^ip igmp snooping"
# (nothing is shown, the device has the default configuration)

    config:
      vxlan: true
      v3_report_suppression: true

Returned: when changed

Sample: "This output will always be in the same format as the module argspec.\n"

before

dictionary

The configuration prior to the module execution.

Returned: when state is merged, replaced, overridden or deleted

Sample: "This output will always be in the same format as the module argspec.\n"

commands

list / elements=string

The set of commands pushed to the remote device.

Returned: when state is merged, replaced, overridden or deleted

Sample: ["ip igmp snooping vxlan", "vlan configuration 100", "ip igmp snooping static-group 233.252.0.10 interface Ethernet1/10"]

gathered

dictionary

Facts about the network resource gathered from the remote device as structured data.

Returned: when state is gathered

Sample: "This output will always be in the same format as the module argspec.\n"

parsed

dictionary

The device native config provided in running_config option, parsed into structured data.

Returned: when state is parsed

Sample: "This output will always be in the same format as the module argspec.\n"

rendered

list / elements=string

The provided configuration in the device-native format (offline).

Returned: when state is rendered

Sample: ["ip igmp snooping vxlan", "vlan configuration 100", "ip igmp snooping static-group 233.252.0.10 interface Ethernet1/10"]
