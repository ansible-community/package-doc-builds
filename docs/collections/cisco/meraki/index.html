Cisco.Meraki¶

Collection version 2.2.1

Plugin Index¶

These are the plugins in the cisco.meraki collection

Modules¶

  • meraki_admin – Manage administrators in the Meraki cloud

  • meraki_alert – Manage alerts in the Meraki cloud

  • meraki_config_template – Manage configuration templates in the Meraki cloud

  • meraki_device – Manage devices in the Meraki cloud

  • meraki_firewalled_services – Edit firewall policies for administrative network services

  • meraki_management_interface – Configure Meraki management interfaces

  • meraki_mr_l3_firewall – Manage MR access point layer 3 firewalls in the Meraki cloud

  • meraki_mr_rf_profile – Manage RF profiles for Meraki wireless networks

  • meraki_mr_settings – Manage general settings for Meraki wireless networks

  • meraki_mr_ssid – Manage wireless SSIDs in the Meraki cloud

  • meraki_ms_access_list – Manage access lists for Meraki switches in the Meraki cloud

  • meraki_ms_l3_interface – Manage routed interfaces on MS switches

  • meraki_ms_link_aggregation – Manage link aggregations on MS switches

  • meraki_ms_ospf – Manage OSPF configuration on MS switches

  • meraki_ms_stack – Modify switch stacking configuration in Meraki.

  • meraki_ms_storm_control – Manage storm control configuration on a switch in the Meraki cloud

  • meraki_ms_switchport – Manage switchports on a switch in the Meraki cloud

  • meraki_mx_content_filtering – Edit Meraki MX content filtering policies

  • meraki_mx_intrusion_prevention – Manage intrustion prevention in the Meraki cloud

  • meraki_mx_l2_interface – Configure MX layer 2 interfaces

  • meraki_mx_l3_firewall – Manage MX appliance layer 3 firewalls in the Meraki cloud

  • meraki_mx_l7_firewall – Manage MX appliance layer 7 firewalls in the Meraki cloud

  • meraki_mx_malware – Manage Malware Protection in the Meraki cloud

  • meraki_mx_nat – Manage NAT rules in Meraki cloud

  • meraki_mx_site_to_site_firewall – Manage MX appliance firewall rules for site-to-site VPNs

  • meraki_mx_site_to_site_vpn – Manage AutoVPN connections in Meraki

  • meraki_mx_static_route – Manage static routes in the Meraki cloud

  • meraki_mx_uplink_bandwidth – Manage uplinks on Meraki MX appliances

  • meraki_mx_vlan – Manage VLANs in the Meraki cloud

  • meraki_network – Manage networks in the Meraki cloud

  • meraki_organization – Manage organizations in the Meraki cloud

  • meraki_snmp – Manage organizations in the Meraki cloud

  • meraki_syslog – Manage syslog server settings in the Meraki cloud.

  • meraki_webhook – Manage webhooks configured in the Meraki cloud
