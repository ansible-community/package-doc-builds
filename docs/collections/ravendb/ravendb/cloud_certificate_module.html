ravendb.ravendb.cloud_certificate module – Download a RavenDB Cloud product client certificate bundle to a local file

Note

This module is part of the ravendb.ravendb collection (version 1.1.0).

You might already have this collection installed if you are using the ansible package. It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install ravendb.ravendb. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: ravendb.ravendb.cloud_certificate.

New in ravendb.ravendb 1.1.0

Synopsis

  • Fetches the client certificate bundle for a RavenDB Cloud product from /api/v1/products/security/certificate/{id} and writes it verbatim to a local file at dest.

  • The API returns a ZIP archive (Content-Type application/octet-stream) containing the client certificate in multiple formats. Typical contents are two PKCS#12 files (one passwordless and one password-protected), a PASSWORD.TXT file with the password for the protected PFX, a README.TXT, and a PEM/ directory with the certificate and private key as PEM files.

  • The module writes the ZIP archive as-is. It does not extract it. Callers who need a specific file (for example a .pfx or a PEM key) should unzip dest themselves.

  • Idempotent by byte comparison. If the file at dest already matches the archive returned by the API, no write is performed and changed=false.

  • The archive is treated as sensitive. Its bytes are never returned in the module result.

  • The file is created with restrictive permissions (mode 0o600) and the module refuses to follow symlinks at dest.

Requirements

The below requirements are needed on the host that executes this module.

  • python >= 3.9

  • requests

Parameters

Parameter

Comments

api_key

string / required

API key used to authenticate against the RavenDB Cloud control-plane API.

Sent in the X-Api-Key header on every request.

api_url

string

Base URL of the RavenDB Cloud control-plane API.

Override only when targeting a non-production environment such as a sandbox.

Default: "https://api.cloud.ravendb.net"

dest

path / required

Absolute path to the local file where the certificate bundle will be written.

The file is a ZIP archive; a .zip extension is recommended.

product_id

string / required

The RavenDB Cloud product id whose certificate bundle should be downloaded.

Attributes

Attribute

Support

Description

check_mode

Support: full

Can run in check_mode. Read operations always execute so predictions are based on real state. Write operations (create, terminate, change) are predicted and never sent to the Cloud API.

Notes

Note

  • Authenticates against the RavenDB Cloud control-plane API using X-Api-Key.

  • Does not require the ravendb python client or the .NET runtime.

Examples

- name: Download RavenDB Cloud product certificate bundle
  ravendb.ravendb.cloud_certificate:
    api_key: "{{ ravendb_cloud_api_key }}"
    product_id: "your-product-id"
    dest: "/etc/ravendb/cloud/client-certificate.zip"

Return Values

Common return values are documented here, the following are the fields unique to this module:

Key

Description

bytes_written

integer

Size in bytes of the ZIP archive written (or that would be written in check mode).

Returned: always

changed

boolean

Whether the file at dest was created or updated.

Returned: always

Sample: true

dest

string

Absolute path the certificate bundle was written to (or would have been written to in check mode).

Returned: always
